# Autonomous systems

Ongoing set of experiments in agent scaffolding — long-horizon, tool-using agents with real side effects.

## Current threads

- **Scheduled agents** — cron-driven workflows that brief me on PRs, inbox, pipeline.
- **Vertical agents** — narrow agents (sales, ops, legal) over real data sources.
- **Evals** — trace-based grading so regressions don't slip between model versions.

## Principles

- Tools first, prompts second.
- Short loops beat long plans.
- Human-in-the-loop where the action is irreversible; full-auto where it isn't.

## Open problems

- Memory that compacts without losing judgment
- Cross-session continuity on shared goals
- Confidence-aware action (ask when unsure, act when not)
